# FIEL — Interactive Judge Experience

Public, credential-free experience for **FIEL — Football Intelligence Engine, Live**.

**[Open the live experience →](https://willian-yudy-f.github.io/fiel-live/)**

![FIEL judge experience](web/public/og.png)

## What this repository contains

This repository contains the React interface used to demonstrate FIEL to hackathon judges and portfolio visitors. It turns the engine's synthetic match data, verified claims and evidence receipts into an interactive replay.

The complete Python engine, Microsoft Foundry workflow, FastAPI service, MCP server, evaluation and 47-test suite live in the team repository:

**[Lmg15186/fiel](https://github.com/Lmg15186/fiel)**

## What visitors can explore

- A minute-by-minute synthetic match replay
- Seeded Monte Carlo win probabilities
- The Microsoft Agent Framework pipeline
- A deterministic rejection and rewrite example
- A clickable receipt showing the events behind an approved claim
- Match Memory baselines and reproducible ground-truth results

No real clubs, players, marks or proprietary match feeds are used.

## Live and fallback data

The interface first connects to the public FIEL API on Azure App Service. If the free-tier service is sleeping or unavailable, the page switches to a labelled cached package generated by the same seeded engine and a stored Microsoft Foundry run.

This keeps the judge experience available without exposing credentials or triggering a new model call.

## Stack

- React 19 and TypeScript
- Vite
- Azure App Service API
- GitHub Actions and GitHub Pages

## Run locally

Requirements: Node.js 22 and npm.

```bash
git clone https://github.com/Willian-Yudy-F/fiel-live.git
cd fiel-live/web
npm ci
npm run dev
```

Vite prints the local URL, normally `http://localhost:5173/fiel-live/`.

## Verify a change

```bash
cd web
npm run check
npm run build
npm run preview
```

The production build is written to `web/dist/`.

## Deployment

Every push to `main` that changes `web/` or the Pages workflow runs a clean `npm ci`, builds the Vite application and deploys `web/dist/` to GitHub Pages.

## Responsible-use note

FIEL is a hackathon prototype using synthetic data. Its predictive metrics and evidence checks demonstrate an architecture; they are not production-grade sporting forecasts and do not replace human editorial review.
